## 📝 Data Entry App

### 🧾 Description
A simple Flutter mobile app that allows users to input and display text.  
It demonstrates stateful widgets, text controllers, and clean UI design principles.

### 🚀 Features
- 🖊️ Text input field for user entry  
- 📤 Submit button to display entered text  
- 💬 Display area showing the submitted content  
- 🧭 Auto-adjusting text area (multiline & flexible height)  
- 🌈 Modern purple-themed UI  
- 🍭 Floating SnackBar with confirmation message  

### 🧱 Tech Stack
- **Flutter**
- **Dart**

### 📸 Screens Overview
- **Splash Screen:** Displays logo & app name.
- **Home Screen:** Includes a flexible text input, submit button, and display card.
